## 2. 維持する仕様

- VRM選択画面に「フルトラッキング設定」「キャリブレーション」の入口を置く。ゲームのスコア表示付近の位置を使うが、ゲームのスコアパネル自体は変更しない。
- 詳細画面を閉じても入口の2ボタンは残す。曲のプレイ中やVRM選択画面の外ではMODの設定画面を開かない。
- 両手トリガー同時押しでメニューを開く操作は追加しない。基本操作はコントローラーで指して、その手のトリガーで押す。
- パネルとキャリブレーションの正面は固定する。頭の動きで追従させない。
- キャリブレーションの正面は取得できる場合は鏡の方向、取得できない場合は開始時の水平視線から決め、表示で区別する。
- 日本語の用語は「キャリブレーション」に統一する。日本語・英語・フランス語・ドイツ語・スペイン語・韓国語・簡体字中国語に対応する。
- LIVE TRACKERSでは推測した部位名を付けない。個体の識別情報と動作状態を確認できるようにする。
- 手動の部位割り当てを優先する。足首・足先は別部位であり、片足2台にも対応する。HMD装着の位置合わせ用トラッカーを腰と決めつけない。
- 足の左右逆・足幅不足の2項目は警告に留め、キャリブレーションを通過させる。他の必須条件と区別する。
- トラッカー割り当て・影・内蔵ライト・カメラガイドは共通設定。HMD内のVRM表示は現行のVRM別保存を維持する。
- カメラガイドはHMDにだけ表示する。LIVには追加の目印を出さない。
- UIの変更でノーツ判定、保存済みの個体識別子、IKの計算条件を意図せず変更しない。

### UI-01：操作部品と状態表示の区別

**変更前（v0.54.0）:** `SettingsPanel`は7行の共通ボタンを作成し、キャリブレーション画面では一部をIK状態や腰の移動量の表示に使っている。押しても動作しない状態表示にもボタン背景とホバー強調が付く。

**実装内容:**

- 開始・確定は大きなピンクの主要ボタン、画面移動は名前と矢印、有効／無効はスイッチにする。
- Tポーズ／直立は両方の選択肢を並べ、現在の選択を明示する。
- 状態表示からボタン枠と押下反応を外す。
- 無効な操作には理由と対応先を表示する。例：「左足が未割り当て」＋［割り当てを確認］。
- 紫の背景、シアンの枠、ピンクの強調を基本にする。

**完了条件:** 押せる・選択中・無効・情報のみを、色と形と文言で判別できる。見た目と当たり判定が一致し、7言語で主要ラベルが読める。

**対象:** [SettingsPanel.cs](../SynthRidersFullBody/SettingsPanel.cs) の `EnsureCreated`、`Tick`、`UpdateText`、[VrUi.cs](../SynthRidersFullBody/VrUi.cs)。

### UI-02：キャリブレーションの段階表示

**流れ:** 準備確認 → 姿勢選択 → カウントダウン → 動作確認。

- 準備確認では、アバター・腰・左右足の「準備OK／未割り当て／追跡喪失」を表示する。設定済みなら毎回割り当てをやり直させない。
- 既存の鏡・固定姿勢・ゴースト・正面ターゲットを同じ手順にまとめる。Tポーズと直立の説明図を用意する。
- 開始後は設定一覧を畳み、目線の高さに残り秒数と短い姿勢指示を表示する。開始後に足元のUI操作を要求しない。
- カウントダウンのキャンセルを明示する。設定変更や画面遷移を行う場合の中断・復元を定義する。
- 成功後は鏡で腰と左右足を動かし、［完了］［やり直す］を選べるようにする。
- 「完了」は処理の成功を示す。実物とアバターの一致まで自動保証した表示にしない。

**完了条件:** 初めて使う人が正面・必要な姿勢・次の操作を判断できる。警告と開始不可を区別し、キャンセルで姿勢固定とカウントダウンを解除できる。繰り返し操作で基準姿勢やUI位置がずれない。

**対象:** [SettingsPanel.cs](../SynthRidersFullBody/SettingsPanel.cs)、[CalibrationDirectionGuide.cs](../SynthRidersFullBody/CalibrationDirectionGuide.cs)、[CalibrationGhostGuide.cs](../SynthRidersFullBody/CalibrationGhostGuide.cs)、[FullBodyMod.cs](../SynthRidersFullBody/FullBodyMod.cs)。

### UI-03：トラッカー割り当ての選択・確認・確定

- 部位選択 → 動かして個体を確認 → 候補選択 → ［割り当てる］で確定する。
- 4秒以内の二度押しを、時間制限のない［確定］［キャンセル］に置き換える。
- 「左足首 ← 個体番号」の対応を表示する。既に別部位へ割り当てられていれば「腰から左足首へ移動」と明示する。
- 自動割り当ては候補一覧を先に表示し、適用前に修正できるようにする。未設定部位だけを補う既存方針を維持する。
- 一覧は安定した識別子で並べ、動作中の強調だけを更新する。切断時には候補を無効化し、別個体を同じ選択として扱わない。
- 足首・足先の装着位置を図で区別する。全12部位と、3台を超えるデバイス構成を扱う。
- 解除も確認対象とする。シリアルのない個体は今回の起動中だけ有効と明示する。

**完了条件:** 個体が再列挙・切断・再接続されても選択対象を取り違えない。移動・解除・自動割り当ては確定前に設定へ反映しない。左右は装着者基準と明示する。

**対象:** [SettingsPanel.cs](../SynthRidersFullBody/SettingsPanel.cs) の `UpdateRoleText` と割り当て入力処理、[Tracking.cs](../SynthRidersFullBody/Tracking.cs) の `Assign`、`AutoAssign`、`Refresh`、[TrackerRoles.cs](../SynthRidersFullBody/TrackerRoles.cs)。

### UI-04：戻る・閉じる・画面移動の統一

- 戻るは左上、閉じるは右上など、全画面で位置と意味を揃える。
- トラッカー／表示／表情／詳細へ移動できるタブを用意する。
- 画面名・現在位置を常に表示する。戻ると閉じるの挙動を区別する。
- 詳細画面を閉じても入口を維持する。未確定の選択は破棄する。
- 空白部分の長押しによる非表示操作を見直す（FIX-01）。

**完了条件:** どの下位画面からも迷わず戻れる。閉じる直前の押下が、背後の入口や次に開いた画面へ連続適用されない。プレイ中は設定UIを表示しない。

### UI-05：文字サイズ・距離・位置の調整

- 文字サイズ「標準／大」、パネルを近づける／遠ざける、位置を戻す操作を追加する。
- 調整値を共通設定へ保存する。復元する距離と拡大率の範囲を決める。
- 長いラベルは2行表示を検討し、説明文は折り返す。重要な操作名・失敗理由を省略だけで済ませない。
- パネル移動は明示的な操作時だけ行う。キャリブレーション中は正面と位置を固定する。

**完了条件:** 近づける・拡大する・戻す操作後もポインターの当たり判定が合う。入口・鏡・正面ターゲットを塞がず、7言語で読める。拡大後も閉じる操作へ到達できる。

**対象:** [VrPanelLayout.cs](../SynthRidersFullBody/VrPanelLayout.cs)、[VrUi.cs](../SynthRidersFullBody/VrUi.cs)、[SettingsPanel.cs](../SynthRidersFullBody/SettingsPanel.cs)、[ModConfig.cs](../SynthRidersFullBody/ModConfig.cs)。

### UI-06：LIVE TRACKERSの情報整理

- 機器名・個体番号・追跡状態・動作中の表示をカード上段へ置く。
- 座標・速度は「詳細表示」で確認できるようにし、全デバイスの情報へのアクセスを維持する。
- 複数ページでは前へ／次へ／ページ数を揃える。1ページの場合は無効なページ送りを表示しない。
- 生座標は取得元ごとの値と明示する。異なるAPIの座標をそのまま比較しないよう短く案内する。
- 複数APIに同じ個体が出る場合、取得元を区別する。根拠のない統合はしない。

**完了条件:** 動かした個体を探せる。表示順が動作量で入れ替わらず、未追跡の機器も確認できる。自動推定の左右・腰表示を追加しない。

### UI-07：操作時のフィードバック

- ホバー時の枠、確定時の短い視覚変化を統一する。
- 対応する機器では短い振動と控えめな操作音を追加し、それぞれ無効にできるようにする。
- 色だけでなく文字とアイコンを併用する。

**完了条件:** 確定1回につき反応は1回。未対応機器や音・振動OFFでも操作でき、追跡やゲーム入力を妨げない。

### UI-08：再キャリブレーションが必要な変更の案内

- 割り当て変更やUltimate補正の変更前に、再キャリブレーションが必要になることを示す。
- Ultimate補正は詳細設定へ配置し、「前後と左右の移動が両方逆の場合」という適用条件を併記する。
- 変更後に「再キャリブレーションが必要」＋［キャリブレーションへ］を表示する。
- 影・ライト・表情など、キャリブレーションを破棄しない変更にも適切な反映状態を表示する。

**完了条件:** ユーザーが変更の影響を確認でき、再キャリブレーションへ移動できる。キャンセルでは値・保存データ・現在のキャリブレーションを変更しない。

## 4. コード上で確認した修正・改善対象

ここでは、現行の処理を確認できたものを挙げる。意図して実装された補助操作やUX上の不足も含み、すべてを実機で再現済みの不具合とは扱わない。

### [ ] FIX-01：空白長押しと閉じる行への移動で、意図せず閉じる経路がある

- **優先度:** P1。**確認:** v0.55.0で修正・自動検証済み。実機確認待ち。
- **変更前の根拠:** `SettingsPanel.Tick`は、カウントダウン外でパネル内の空白を指してトリガーを1.25秒保持すると閉じる。また、トリガーを保持したまま閉じる行へ移ると0.35秒で閉じる。
- **問題:** 明示されていない操作で画面が消える可能性があり、他の操作の押下保持と区別しにくい。
- **対応:** UI-04で明示的な閉じる操作へ統一する。以前の「閉じられない」症状を補助した経緯があるため、単純削除だけで済ませず、押下開始・解放・再表示の入力状態を確認する。
- **完了条件:** 空白で押し続けても閉じない。閉じるは狙って確定でき、片手・両手・視線フォールバック・再表示で閉じられなくなる退行がない。

### [ ] FIX-02：割り当て解除とUltimate補正が、その場で即時適用される

- **優先度:** P1。**確認:** v0.57.0で修正・自動検証済み。実機確認待ち。
- **変更前の根拠:** `SettingsPanel.Tick`の個体選択画面の解除行は即座に`tracking.Assign(selected, null)`を呼ぶ。Ultimate補正行は`ToggleUltimateRotation`を返し、`FullBodyMod.HandlePanelCommand`が設定変更・キャリブレーション無効化・保存を行う。
- **問題:** 個体選択には二度押しが必要なのに、追跡構成を崩し得る解除や補正変更は1回で確定する。
- **対応:** UI-03・UI-08の確認表示に統合する。単純な表示設定などへ一律に確認ダイアログを増やさない。
- **完了条件:** 変更内容を確認してから適用でき、キャンセルで追跡設定が維持される。

### [ ] FIX-03：情報専用行・空行・無効操作の見た目が操作ボタンと共通

- **優先度:** P2。**確認:** v0.55.0で修正・自動検証済み。実機確認待ち。
- **変更前の根拠:** `EnsureCreated`が7行すべてにボタン背景を作り、`Tick`は行番号で強調する。キャリブレーションのIK状態・腰情報や、選択肢のない行にも共通部品を使う。例外的な色分けはあるが、操作種別を一元管理していない。
- **対応:** UI-01で行の種類・有効状態を表示と入力処理の両方へ反映する。
- **完了条件:** 情報のみ・空行に押下反応が出ない。操作不可の理由を読める。

### [ ] FIX-04：列挙順依存の個体一覧と、一方向のページ送り

- **優先度:** P2。**確認:** v0.57.0で修正・自動検証済み。実機での接続切り替え・ページ操作は確認待ち。
- **変更前の根拠:** `Tracking.Refresh`はAPIの列挙順で一覧を再生成し、`UpdateRoleText`はその一覧を3台ずつ表示する。部位・個体・表情は「次へ」の循環操作。v0.55.0で1ページだけの個体・表情のページ送りは情報表示に変更したが、安定した並べ替えと前へ／次へは未実装。
- **対応:** UI-03・UI-06で順序を安定化し、前へ／次へを整える。表示に使った個体キーで確定し、再接続時の一時ID再利用を確認する。
- **完了条件:** 列挙順の変化・切断・再接続でも確認中の個体が勝手に変わらない。端のページと1ページだけの状態が分かる。

## 5. 報告済み・原因未確定・実機検証待ちの問題

### [ ] INV-01：小さいアバター・足先だけの入力で、つま先が伸びる／浮いて見える

- **優先度:** P1。**確認:** ユーザー報告あり。現在の原因は未確定。
- **既存対策:** v0.50.0以降、片足1台では足首に対するつま先の基準回転を維持する。足首＋足先の2台では独立入力を維持する。
- **確認済みの構造:** `AvatarCalibrationPose.FitSize`と`AvatarScaleMath.TryFit`は、モデルの足首とトラッカー中心の高さをサイズ合わせに使う。足裏・床面・装着高さは入力に持たず、足先のみの割り当てでも同じ経路になる。
- **残存ログの限界:** ローカルに残っていたv0.49.0のログでは、腰＋左右足先のキャリブレーションを確認した。ただし新しいつま先補正の実行記録はなく、足裏メッシュと床の距離もない。ルートYや目標Yから「何cm浮いた」とは断定できない。
- **次の作業:** 現行版で、小・標準・大のモデルを、足首のみ／足先のみ／両方で比較する。足首・つま先のIK前後の回転・位置、VRIK終端とHumanoidボーンの対応、床面と足裏の基準を同一座標系で確認する。
- **修正条件:** 原因が装着高さ、ボーン対応、基準姿勢、後段の上書きのどこにあるか特定してから修正する。全モデルを一律に下げる変更は行わない。
- **完了条件:** つま先の不自然な伸び・接地ずれが改善し、元々正常だったモデル、2台構成、再キャリブレーション、シーン移動で退行しない。
- **対象:** [AvatarCalibrationPose.cs](../SynthRidersFullBody/AvatarCalibrationPose.cs)、[AvatarScaleMath.cs](../SynthRidersFullBody/AvatarScaleMath.cs)、[CalibratedToeRotation.cs](../SynthRidersFullBody/CalibratedToeRotation.cs)、[AdditionalTrackerTargets.cs](../SynthRidersFullBody/AdditionalTrackerTargets.cs)、[AvatarIK.cs](../SynthRidersFullBody/AvatarIK.cs)。チェックリストT1〜T3。
