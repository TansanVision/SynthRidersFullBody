# Synth Riders Full Body

PC版 Synth Riders のアバターに、腰や足などのトラッカーの動きを反映する非公式MelonLoader MODです。ゲーム内のVRM選択画面から、トラッカーの割り当て・キャリブレーション・表示設定を操作できます。

**このガイドの対象：v0.50.0**

> 初めて使う方は「導入」→「トラッカーを割り当てる」→「キャリブレーション」の順に進めてください。ゲームを起動するたびに、キャリブレーションが必要です。

## できること

- 腰・左右の足を使ったフルトラッキング。頭・肘・手首・膝・足先にも追加のデバイスを割り当てられます。
- アバターを固定したTポーズ／Standing（直立姿勢）でのキャリブレーション。
- 検出したデバイスのシリアル番号・座標・動作状態の表示。
- 配信・録画用カメラの位置を、HMD内だけに水色の球で表示。
- アバターの影・内蔵ライト・HMD内での自分のアバター表示の切り替え。

ノーツ判定やスコアは変更しません。異種コントローラーの割り当てはアバターとMODのUI用であり、ゲーム本体のノーツ判定用入力を置き換える機能はありません。

## 必要な環境

| 項目 | 必要なもの |
| --- | --- |
| ゲーム | Windows PC版 Synth Riders 3.x。Quest単体版は対象外です。 |
| MODローダー | MelonLoader 0.7.x（IL2CPP / net6）。本プロジェクトのビルド参照は0.7.3です。 |
| VR機器 | HMDと左右コントローラー。SteamVRでHMD・トラッカーを追跡できる環境。 |
| 基本のトラッカー構成 | 腰1台、左足1台、右足1台。足は装着位置に応じて足首／足先へ割り当てます。 |
| アバター | ゲームで読み込めるHumanoid（人型の骨格）のアバター。標準モデルも対象です。 |

Quest 3とVIVE Tracker 3.0／Ultimate Trackerなどを組み合わせる場合も、先に各機器をSteamVRで使える状態にしてください。**HMD・コントローラー・トラッカーの追跡空間を、外部の位置合わせツール等で揃えておく必要があります。** このMODは継続的な空間のずれ補正を行いません。Ultimate Tracker向けの任意の180度・水平位置補正も、外部ツールによる追跡空間の位置合わせを代替するものではありません。

機種名だけで対応を判断するのではなく、ゲーム起動後に `LIVE TRACKERS` で姿勢が取得できていることを確認してください。すべての機器の組み合わせ・アバター・ゲーム更新版で実機確認が済んでいるわけではありません。

### Ultimate Trackerで校正が失敗する場合

`pose=yes`は位置・回転を取得できたという意味で、HMDとトラッカーの空間合わせが正しいことまでは保証しません。Ultimate Trackerでは、先に [HTCのVIVE Space Calibratorの手順](https://www.vive.com/us/support/ultimate-tracker/category_howto/calibrating-the-trackers.html) で位置合わせを行い、SteamVR内で実物と表示位置が合っているか確認してください。HTCは、VIVE Space Calibratorと別の空間補正ツールを同時に有効にすると位置合わせへ影響すると案内しています。[HTCの対処方法](https://www.vive.com/ca/support/ultimate-tracker/category_howto/tracker-position-in-vr-and-real-world-dont-match.html)

v0.47.0では、足の左右逆（`Feet reversed`）と足幅不足（`Feet too close`）は警告のみです。Standing・Tポーズともに、この2つを理由に校正を停止しません。警告はカウントダウン中と完了後に表示され、追加の確認操作は不要です。`Calibration complete` が出たら鏡で動きを確認してください。自動で役割を交換することはありません。

`Feet reversed vs FRONT` は固定した正面に対して足の座標が逆という意味です。割り当ての取り違えだけでなく、追跡空間の不一致でも起こります。正面・視線・追跡状態・腰の高さ・静止状態のチェックと、Tポーズでの腕のチェックは引き続き行います。

正面と割り当てが正しいのに失敗する場合は、一度校正を試し、その起動の `Latest.log` を共有してください。`Calibration check [failed]` と `Calibration tracking [failed]` に、判定時の座標・向き・個体・追跡状態を記録します。詳しい調査結果は [Ultimate Trackerの調査メモ](docs/ULTIMATE_TRACKER_INVESTIGATION.md) を参照してください。

## 導入

1. ゲームを終了します。
2. Synth RidersにMelonLoaderを導入します。ローダーの導入方法は [MelonLoader公式Wiki](https://melonwiki.xyz/) を参照してください。
3. MelonLoaderを導入した状態でゲームを一度起動し、初期処理が終わったら終了します。
4. ビルド済みの `SynthRidersFullBody.dll` を、ゲームのインストール先にある `Mods` フォルダーへ配置します。

   ```text
   SynthRiders/
   ├─ Mods/
   │  └─ SynthRidersFullBody.dll   ← ここに配置
   ├─ MelonLoader/
   └─ UserData/
   ```

5. SteamVRで各デバイスの追跡状態を確認し、ゲームを起動します。
6. ゲーム内のVRM選択画面を開き、`FULL BODY SETTINGS` と `CALIBRATE FULL BODY` が表示されることを確認します。

MODの導入に使うのは `SynthRidersFullBody.dll` です。プロジェクト内の `Libs` フォルダーやUnity参照DLLは、`Mods` にコピーしません。`openvr_api.dll` は通常SteamVRのインストール先から自動検出します。

ソースコードからビルドする場合の出力先は `SynthRidersFullBody/bin/Release/net6.0/SynthRidersFullBody.dll` です。ビルド方法は [ビルド手順](docs/BUILDING.md) を参照してください。配布ZIPに含まれるライセンス・第三者表記のテキストも保管してください。

## 画面を開く・操作する

VRM選択画面に、次の2つの入口ボタンが表示されます。通常はゲームのスコア表示付近の位置に、独立したボタンとして配置されます。位置を取得できない場合はメニュー横に配置されます。

| ボタン・画面 | 用途 |
| --- | --- |
| `FULL BODY SETTINGS` | 設定画面を開きます。 |
| `CALIBRATE FULL BODY` | キャリブレーション画面を開きます。 |
| `TRACKER ROLES` | 身体の部位とデバイスを対応付けます。 |
| `LIVE TRACKERS` | デバイスの状態を確認します。設定・校正画面の右側に表示されます。 |
| `VISUAL OPTIONS` | カメラの目印、影、ライト、HMD内のアバター表示を切り替えます。 |
| `Tracking: ON / OFF` | 校正済みのフルトラッキングを一時的に有効／無効にします。 |
| `Ultimate 180 correction: ON / OFF` | Ultimate Trackerの前後・左右の移動が両方逆の場合に180度補正します。切り替え後は再校正します。 |
| `Close panel` | 詳細画面を閉じます。入口の2ボタンは残ります。 |

**コントローラーで項目を指し、その手のトリガーを押します。** ポインターは左が水色、右がピンクです。画面を開いた後はいったんトリガーを離してから次の項目を押してください。コントローラーの姿勢を取得できない場合は、項目を見る＋トリガーの操作へ切り替わります。

パネルは開いた位置に固定され、頭の動きには追従しません。両手トリガーやグリップの同時押しで画面を開く操作はありません。曲のプレイ中やVRM選択画面を離れた後は、設定・校正UIを表示しません。

### Ultimate Trackerの前後・左右への動きが逆の場合

1. `FULL BODY SETTINGS` の `Ultimate 180 correction` を **ON** にします。
2. `CALIBRATE FULL BODY` を開き、StandingまたはTポーズで再キャリブレーションします。
3. 片足を前・横へ動かし、同じ方向へ動くことを鏡で確認します。続いて腰の移動・回転も確認します。

補正の初期値はOFFです。ONでは、SteamVRが `VIVE Ultimate Tracker` として報告する機器の位置と回転を、校正時に固定した中心の周りで水平に180度回転します。腰・足・膝など、割り当てたUltimate Trackerすべてへ適用します。QuestのHMD・コントローラーやVIVE Tracker 3.0には適用しません。前後だけが逆の現象にはこの設定は対応していません。

v0.49.0から、腰もUltimate Trackerの場合は、**校正開始時に直立したHMDの真下へ腰の水平位置を合わせる**処理を追加しています。同じ移動をUltimate Tracker全体へ適用し、足や腰の回転に大きな空間の位置ずれが混ざることを防ぎます。追跡中は基準を固定するので、頭を動かしてもその位置合わせは変わりません。校正を開始するときから正面を向いて直立してください。腰が対象外・未追跡の場合は、この水平位置合わせを行いません。

この水平補正は試験的な機能です。計算テストは実行済みですが、Ultimate Tracker実機での改善確認は完了していません。

設定は全アバター共通で保存され、シーン移動でも引き継ぎます。切り替えると古い校正は解除されます。`LIVE TRACKERS` の座標は引き続きAPIの生座標です。補正後の動作はアバター・部位マーカーで確認でき、ログの `Ultimate Tracker 180 correction` と `raw / world` にも記録されます。

## トラッカーを割り当てる

### 最初は腰と左右の足を設定する

1. `FULL BODY SETTINGS` → `TRACKER ROLES` を開きます。
2. 設定したい部位を選びます。
3. その部位に付けたトラッカーを軽く動かし、一覧の `MOVING` とシリアル番号で個体を確認します。
4. その個体を選びます。`CONFIRM` と表示されたら、**4秒以内に同じ個体をもう一度選んで確定**します。
5. 腰・左足・右足を設定します。項目が見えない場合は `Next body parts`、個体一覧では `Next device page` を押します。

**Left / Rightは、装着している自分から見た左右です。鏡の中の見た目で判断しないでください。** HMDに付けた位置合わせ用トラッカーを `Waist` に割り当てないようにしてください。外部の空間補正にだけ使用する個体は、このMODでは未割り当てのままで構いません。

| UIの部位名 | 装着・反映先 |
| --- | --- |
| `Waist` | 腰 |
| `Left ankle` / `Right ankle` | 左／右の足首 |
| `Left toes` / `Right toes` | 左／右の足先 |
| `Head` | 頭。未設定ならゲームのHMD入力を使います。 |
| `Left wrist` / `Right wrist` | 左／右の手首。未設定ならゲームの手の入力を使います。 |
| `Left elbow` / `Right elbow` | 左／右の肘の曲がる位置 |
| `Left knee` / `Right knee` | 左／右の膝の曲がる位置 |

- 1つの個体を複数の部位には割り当てられません。別の部位へ選ぶと、以前の部位から移動します。
- 解除するには、部位を選んで `CLEAR / USE GAME DEFAULT` を押します。腰や足の必須入力を解除した場合は、そのままではフルトラの校正はできません。
- 割り当てを変更した後は、再キャリブレーションが必要です。

### AUTOを使う場合

鏡へ体を向け、足を軽く開いて立ち、`AUTO: suggest waist / ankles / toes` を選びます。確認表示になったら4秒以内にもう一度押します。

`AUTO` は、**未設定の腰・足首・足先に候補を入れる機能**です。既存の割り当ては上書きせず、頭・肘・手首・膝は自動設定しません。判別できない部位は未設定になります。結果は必ず個体を動かして確認し、必要なら手動で直してください。

### 足首と足先の両方に付ける場合

片足に2台付け、`ankle` と `toes` に別々の個体を設定できます。足首を位置の基準にし、足先の入力も使って向きを反映します。足先だけに1台付ける構成では、`toes` だけを設定できます。

片足1台の場合（`ankle` または `toes` の片方だけ）、足首とつま先を別々には計測できません。v0.50.0から、足全体はトラッカーへ追従させ、足首に対するつま先の角度は校正時の姿勢に保ちます。足裏が合っているのにつま先だけが反る動作を抑えるための補正です。足首と足先に別々の2台を割り当てた場合は、独立した足先の動きを引き続き反映します。

追加部位には、アバター側の対応するIK（骨格を動かす仕組み）が必要です。足首・足先を同時に使う場合は、足先ボーンも必要です。条件を満たさない場合は校正画面に理由が表示されます。

### LIVE TRACKERSの見方

| 表示 | 意味 |
| --- | --- |
| `SteamVR` / `Unity XR` | デバイス情報の取得元 |
| `#`番号・`S/N` | デバイス番号とシリアル番号 |
| `X / Y / Z` | 取得元の追跡空間での座標（メートル）。アバター上の座標ではありません。 |
| `m/s` | 移動速度 |
| `MOVING` | 移動または回転を検出した個体 |
| `Tracking lost` / `LOST` | 個体は見つかっていますが、姿勢を取得できない状態 |

この一覧に推測した身体の部位名は表示しません。実際の割り当ては `TRACKER ROLES` で確認します。同じ個体がSteamVRとUnity XRの両方に見える場合は、取得元ごとに表示されます。全台が見えない場合は `Next tracker page` を押してください。

## キャリブレーション

キャリブレーションは、トラッカーとアバターの身体の位置・向きを合わせる操作です。

### 正面と立つ位置

1. 使用するアバターを選び、校正したい場所で直立します。
2. `CALIBRATE FULL BODY` を押します。
3. **床の `FRONT` 矢印の方向へ、顔と身体を向けます。**

`FRONT = MIRROR` の場合は、ゲームの `Toggle mirror` で表示する鏡の方向が正面です。MODは校正中にゲームの鏡を一時表示します。鏡を取得できない場合は `FRONT = ARROW` となり、画面を開いた瞬間の水平な視線方向を正面に固定します。

設定パネルや入口ボタンの方向が、校正の正面とは限りません。画面を開いた後に立つ位置を変えた場合は、入口の `CALIBRATE FULL BODY` をもう一度押して基準位置を取り直してください。

### Tポーズで校正する（初期モード）

1. `Pose: T-pose` になっていることを確認します。アバターは両腕を水平に広げた姿勢で固定されます。
2. 両足を床に置き、軽く開いて、正面を向いて立ちます。
3. `START T-POSE CALIBRATION` を押します。この時点で腕を広げておく必要はありません。
4. **5秒のカウントダウン中に、両腕を左右へ肩の高さで広げます。** 手を交差させず、左右の高さを揃えてください。
5. 正面の目の高さにあるターゲット点を見て、0になるまで静止します。足元を見る必要はありません。点がオレンジになったら、表示される案内に合わせて姿勢を直します。
6. `Calibration complete` が出たら完了です。腕を下ろし、鏡で腰・左右の足の動きを確認します。
7. `Close panel` で詳細画面を閉じます。

鏡では水色の骨格ガイドと、実際の両手位置を示すピンクの輪を確認できます。校正が完了するまではアバターの姿勢が固定されるため、自分の動きに追従しないのは正常です。

### Standingで校正する

腕を広げるTポーズを使わない場合は、`Pose` を押して `standing` に切り替えます。

1. アバターのように腕を下げ、両足を軽く開いて直立します。
2. `CALIBRATE STANDING` を押します。
3. 正面のターゲット点を見ながら、**3秒間**静止します。
4. `Calibration complete` が出たら、鏡で動きを確認します。

Standingでも腰と左右足の追跡が必要です。大きく下を向く、トラッカーが動き続けるなどの場合は校正に失敗します。足の左右逆・足幅不足は警告を表示して校正を続けます。

### 失敗した場合・モデルのサイズについて

画面下部の理由を確認し、姿勢や割り当てを直して `RETRY CALIBRATION` を押してください。校正途中で閉じるとキャンセルされ、固定した姿勢とサイズを元へ戻します。

モデルの高さは校正中にユーザーへ合わせて均等に調整します。小さいモデルは拡大、大きいモデルは縮小し、体型の比率を保ちます。VRMファイル自体は変更しません。体型やトラッカーの装着位置による差は残るため、足裏と床が厳密に一致するとは限りません。サイズにかかわらず、まず直立し、両足を床へ置いた状態で校正してください。

## 配信カメラ・アバターの表示設定

`FULL BODY SETTINGS` → `VISUAL OPTIONS` から変更できます。これらの操作にキャリブレーションは不要です。

| 設定 | 動作 |
| --- | --- |
| `Camera guide in headset` | `ON`で配信・録画用カメラの位置に水色の球と `CAPTURE CAMERA` を表示します。目印はHMD向けで、配信映像には表示しない設計です。初期値は`OFF`です。 |
| `VRM cast/receive shadows` | `OFF`でアバターが影を落とす・受ける処理を無効にします。初期値は`ON`です。 |
| `VRM lights` | `OFF`でアバターに含まれるライトを無効にします。ライトを含まないモデルでは効果がありません。初期値は`ON`です。 |
| `VRM in headset` | 自分のアバターをHMD内に表示するか切り替えます。配信カメラ側のアバター表示は維持します。 |

影・ライトの設定はアバターを対象とし、ステージ全体は変更しません。軽くなる程度はモデルによって異なり、重いシェーダーやポリゴン数を減らす機能ではありません。

### カメラの目印を探す

1. ゲーム側で三人称・Custom Cameraなど、配信／録画用カメラを有効にします。
2. `Camera guide in headset: ON` にします。
3. `VISUAL OPTIONS` のカメラ検出状態と、方向・距離の表示を確認し、その方向の水色の球を探します。

一人称・カメラOFFでは対象の球を表示しません。LIV使用時も追加の球は出さず、LIV側の目印を使います。カメラを検出できない場合や表示処理に問題がある場合は、画面の状態表示とログを確認してください。

## 設定の保存とシーン切り替え

設定はゲームのインストール先の `UserData/SynthRidersFullBody.json` に保存されます。通常はゲーム内UIだけで設定できます。

| 項目 | 保存・引き継ぎ |
| --- | --- |
| トラッカーの割り当て | 全アバター共通。シリアル番号がある個体は次回起動時も復元します。シリアル番号がない個体は起動ごとに再選択が必要です。 |
| Tracking、影、ライト、カメラガイド | 全アバター共通。シーン切り替え・再起動後も設定を引き継ぎます。 |
| Ultimate 180 correction | 全アバター共通。シーン切り替え・再起動後も設定を引き継ぎます。設定キーは `UltimateTrackerRotate180`。 |
| HMD内のアバター表示 | アバターごとに保存し、読み込み後に再適用します。 |
| キャリブレーション結果 | 今回のゲーム起動中のみ保持します。同じアバターのシーン移動では、準備が整い次第、復帰を試みます。 |

**次の場合は再キャリブレーションしてください。**

- ゲームを起動し直した。
- 別のアバターへ変更した。
- トラッカーの割り当てや装着位置・向きを変えた。
- `Ultimate 180 correction` を切り替えた。
- v0.48.0からv0.49.0へ更新した（補正ONのままで再校正してください）。
- SteamVRの原点や、外部ツールの追跡空間の位置合わせを変更した。
- 画面に再校正が必要と表示された。

シーン読み込み中は、一時的に頭と手だけの追跡になる場合があります。腰の追跡を失った場合もゲーム標準の動きへ戻し、復帰後は元の校正を使ってフルトラへ戻します。

## 困ったときは

| 症状 | 確認すること |
| --- | --- |
| 入口ボタンがない | VRM選択画面を開いているか確認してください。プレイ中は非表示です。ゲームの `Mods` にDLLが1つだけあるか、`Latest.log` にMOD名とバージョンが出るかも確認します。 |
| 項目を押せない | いったん左右のトリガーを離し、指している手のトリガーを押してください。ポインターが項目に重なる位置で操作します。 |
| パネルを閉じにくい | `Close panel` を指して押します。狙いにくい場合はパネル内の空白部分を指して約1.25秒トリガーを長押しすると閉じられます。カウントダウン中は空白の長押しは無効です。 |
| `HMD: missing` / トラッカーが見えない | SteamVRで機器が追跡中か確認します。`LIVE TRACKERS` の個体名だけでなく、姿勢が更新されているかも確認してください。 |
| 台数は揃っているのに校正できない | `TRACKER ROLES` で腰と左右足の割り当てを確認します。台数が揃っていても、自動では役割を確定しません。 |
| `Avatar: missing` | ゲームでアバターを選び、読み込みを待ちます。人型の骨格を持つモデルかも確認してください。 |
| `Check WAIST role` / 腰が頭に引っ張られる | HMD装着のトラッカーを腰に選んでいないか確認します。腰だけを動かして個体を特定し、割り当てを直して再校正します。 |
| 左右の足が逆・ターン後にずれる | 装着者基準の左右、床の`FRONT`矢印、各デバイスの追跡空間を確認します。装着ずれや外部の空間合わせを直した後は再校正してください。 |
| `Calibration failed` | 画面下部の理由を確認します。足を軽く開く、目の高さの点を見る、トラッカーを静止させる、Tポーズでは両腕の高さを揃えることを確認します。 |
| 校正後に追従しない | `Tracking: ON` と `Calibration complete` を確認します。腰・左右足が追跡中か確認し、鏡で動きを見てください。 |
| シーン移動後に頭と手だけになる | アバターの読み込みと追跡復帰を待ちます。戻らない場合はVRM選択画面で状態を確認し、再校正してください。繰り返す場合はログを添えて報告してください。 |
| モデルが大きすぎる・姿勢が崩れる | 正しい腰・足を割り当て、直立した状態で再校正します。別のアバターでも起きるかを確認し、改善しなければモデル名とログを添えてください。 |
| カメラの球がない | ゲーム側の配信用カメラとガイドがONか確認します。一人称・OFF・LIVでは球は表示しません。`VISUAL OPTIONS` の状態・方向・距離を確認してください。 |
| ゲームが重い | `VRM cast/receive shadows` と `VRM lights` をOFFにして比較します。効果が小さい場合は別の軽いアバターでも確認してください。 |

## 更新・アンインストール

**更新：** ゲームを終了してから、`Mods/SynthRidersFullBody.dll` を新しいDLLで置き換えます。古いDLLを別名で同じフォルダーに残すと重複して読み込まれるため、`Mods` の外へ移してください。設定ファイルは残せます。起動後はキャリブレーションを行います。

**削除：** ゲームを終了して `Mods/SynthRidersFullBody.dll` を削除します。設定も消す場合は `UserData/SynthRidersFullBody.json` を削除します。HMD内のアバター表示はゲーム側の設定にも反映されるため、必要ならゲームのアバター設定で戻してください。

**設定を初期化：** ゲームを終了し、`UserData/SynthRidersFullBody.json` を別の場所へバックアップしてから元のファイルを削除します。次回起動時に既定設定を作成するので、トラッカーの割り当てと校正をやり直してください。

## 不具合を報告するとき

ゲームのインストール先にある **`MelonLoader/Latest.log`** を、問題が起きた起動のものとして保存し、次の情報と一緒に共有してください。

- MOD・ゲーム・MelonLoaderのバージョン。
- HMD、トラッカー、コントローラーの機種と台数。HMD装着の位置合わせ用トラッカーの有無。
- アバター名、部位の割り当て、T-pose／Standingのどちらを使ったか。
- 発生した画面・シーン、再現する操作手順、期待する動作と実際の動作。
- 可能なら画面のスクリーンショットまたは動画。
- カメラの問題では、ゲーム側のカメラモードと `VISUAL OPTIONS` の状態表示。

公開Issueへ添付するログでは、シリアル番号・ユーザー名・個人情報を含むパスを伏せてください。同じ個体には同じ伏せ字を使うと、割り当ての問題を確認しやすくなります。設定ファイルにも個体番号が保存されるため、公開するときは同様に確認してください。

詳しく動作を確認する場合は [実機確認チェックリスト](REAL_DEVICE_CHECKLIST.md) を参照してください。過去の変更履歴・ビルド手順・技術情報は [開発メモ](docs/DEVELOPMENT_NOTES.md) にまとめています。

## ソースからビルドする

公開ソースにはゲーム・Unity・MelonLoaderの参照DLLを含めません。自分のゲーム環境で生成した参照DLLを用意する方法は [ビルド手順](docs/BUILDING.md) を参照してください。ゲームのexe自体はビルドに不要です。

ソース・MODの配布ZIPを作成する方法と、過去のGit履歴を含めずに公開する手順は [公開・配布手順](docs/PUBLISHING.md) を参照してください。
